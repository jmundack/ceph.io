v11.1.1 Kraken rc released

Dec 27, 2016 TheAnalyst

This is a release candidate for kraken, the next stable release series.

Major Changes from Jewel ¶

  • RADOS:
    • The new BlueStore backend now has a change in the on-disk format, from the previous release candidate 11.1.0 and there might possibly be a change before the final release is cut
