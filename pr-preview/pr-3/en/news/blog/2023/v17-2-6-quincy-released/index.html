v17.2.6 Quincy released

Apr 10, 2023 yuriw

This is the sixth backport release in the Quincy series. We recommend all users update to this release.

Notable Changes ¶

  • ceph mgr dump command now outputs last_failure_osd_epoch and active_clients fields at the top level. Previously, these fields were output under always_on_modules field.

  • telemetry: Added new metrics to the 'basic' channel to report per-pool bluestore compression metrics. See a sample report with ceph telemetry preview. Opt-in with ceph telemetry on.
